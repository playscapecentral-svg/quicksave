Frequently asked questions

Is QuickSave free?

Yes. It runs locally on this machine, so there are no accounts, quotas or watermarks.

Which sites work?

Any site the underlying resolver supports — over a thousand extractors, including YouTube, Facebook, Instagram, TikTok, Vimeo, Dailymotion, Reddit and X. Some private or login-only posts cannot be fetched.

Why did a download fail?

Sites sometimes rate-limit, region-lock or require sign-in cookies. If a link fails, try again later, or open the video in your browser first to check it is public.

What's the difference between formats?

Higher resolutions look better but make bigger files. Video-only formats are merged with the best audio automatically; audio-only formats can be saved directly or converted to MP3.

Can I convert a file I already have?

Yes — use the File Converter above. It handles MP4, MP3, WEBM, MOV, MKV and GIF, up to 200 MB.

Is there a browser button?

Yes — the QuickSave Helper extension adds a Download button on video pages and opens QuickSave with the link already filled in. See the README for install steps.
